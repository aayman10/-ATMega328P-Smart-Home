# ATMega328P Smart Home

Mobile-controlled smart home system using ATMega328P microcontroller.

## Features
- Bluetooth-based mobile control
- LED ON/OFF control
- Servo motor door control
- UART communication
- Home automation system

## Drivers
- DIO Driver
- USART Driver
- Timers Driver
- Servo Driver
- LED Driver

## Tools & Technologies
- Embedded C
- AVR-GCC
- ATMega328P
- Proteus
